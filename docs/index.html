Prtisan

A resumable PR integration engine with frozen authority, sandboxed repair, guarded squash merge, and safe restacking.

Raw Markdown for agents · Raw source

Workflow

prtisan init plan --cwd /repo
prtisan init apply <setup-plan-id>
prtisan plan --cwd /repo
prtisan apply <plan-id>
prtisan status <plan-id>
prtisan export <plan-id>

An immutable plan freezes the complete open train. Applying it journals every effect and can resume without duplicating mutations. Required checks and human approvals remain hard gates.

GitHub Issue And PR Conventions

Codex blockers and repair authority require a linked issue or all structured PR-body sections declared in .prtisan/manifest.json.

State

Journal and leases use the XDG state directory. Artifacts, caches, and a dedicated Prtisan Codex home use the XDG data directory. Credentials and execution records never live in the target repository.
